Available in v0.0.2

Choose the model that answers.

The universal model picker lets you select and switch actual models — a local deterministic engine, optional bitnet.cpp or llama.cpp runtimes, or a web adapter. Add adapter offers built-in templates (OpenAI, OpenRouter, Groq, Together, DeepSeek, Ollama, LM Studio) as well as any OpenAI-compatible endpoint you trust. Web access is possible and enabled by default with a Settings switch, and no request happens until you select a web adapter. Conversations continue across switches, and every reply carries clear model attribution.

Ask on GitHub
What is Origin Agent?

A native, mobile-first, model-agnostic intelligent agent environment for Android. It combines conversation, local tools, persistent memory and a verifiable trust pipeline in one app. Origin AI is its intelligence foundation; Origin Agent is the product.

Can I use it today?

Yes. v0.0.2 (universal model picker, adapters and web access) and v0.0.1 are published on GitHub Releases with the Origin chat, Capabilities, Memory, Trust and Settings screens. Download the APK from a source you trust and verify the SHA-256 in the release notes.

Does it work offline?

Yes, fully. The deterministic local engine, calculator, date/time, notes, knowledge search and trust ledger all work with no connection. Optional model runtimes are user-supplied, and remote endpoints are opt-in.

Does it make network requests?

Only when you choose to. Web access is possible and enabled by default, but you can switch it off in Settings at any time. There is no telemetry, analytics or required cloud service: the app reaches the network only if you select a web adapter (a built-in template or your own OpenAI-compatible endpoint). Local models stay fully offline, and every reply tells you which model answered.

Where does my data live?

On your device, in local append-only memory. There is no mandatory account and no synchronisation. You can search it, export it as portable JSON, or clear it with confirmation.

Which models are supported?

v0.0.1 uses a deterministic local engine. v0.0.2 adds a picker for local deterministic, optional bitnet.cpp and llama.cpp models, plus web adapters — built-in templates (OpenAI, OpenRouter, Groq, Together, DeepSeek, Ollama, LM Studio) and any OpenAI-compatible endpoint you add yourself. Strategic candidates — BitNet b1.58 2B4T, LFM2.5-class, optimized sub-1B and Qwen-class compact — are evaluated on evidence, never assumed. See the model registry.

Is it on Google Play?

No, not by design for now. APKs are distributed through GitHub Releases, and F-Droid metadata is included in the repository. No Play Store dependency, no ads, no proprietary SDKs.
